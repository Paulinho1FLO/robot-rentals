## About

SAIT course assignment to practice JavaScript fundamentals including DOM manipulation, event listeners, and dynamic calculations.

## Features

- Switch between robot models (XYZ and CPRG)
- Set rental duration via prompt
- Real-time cost calculation
- Retro pixel-art styling
